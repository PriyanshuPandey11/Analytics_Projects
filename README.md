An end-to-end SQL analytics project built using the **Olist Direct-to-Consumer (DTC) e-commerce dataset**. This project focuses on transforming raw transactional data into meaningful business insights by writing optimized SQL queries to analyze customer behavior, sales performance, order trends, product performance, and operational metrics.

**Key Highlights**

* End-to-end SQL data analysis
* Complex joins across multiple relational tables
* Common Table Expressions (CTEs) and subqueries
* Aggregate functions and window functions
* Business KPI development
* Customer, product, and sales analysis
* Data-driven business insights and recommendations
* Well-documented SQL scripts for analytical reporting
